# myomlt

> Projeto web em **HTML** para apresentar conteúdo de forma simples, direta e acessível.

## 📌 Sobre o projeto

O **myomlt** é um repositório focado em uma estrutura leve baseada em HTML, ideal para páginas estáticas, protótipos rápidos ou publicação de conteúdo na web.

## 🚀 Objetivos

- Manter uma base limpa e fácil de evoluir
- Priorizar simplicidade e organização
- Facilitar publicação e manutenção de páginas estáticas

## 🧱 Tecnologias

- **HTML** (100%)

## 📁 Estrutura sugerida

```txt
myomlt/
├── index.html
├── assets/
│   ├── css/
│   ├── js/
│   └── img/
└── README.md
```

> Caso sua estrutura atual seja diferente, este README pode ser ajustado facilmente.

## ▶️ Como visualizar localmente

Como é um projeto HTML estático, basta abrir o arquivo principal no navegador:

1. Clone o repositório:
   ```bash
   git clone https://github.com/m1st1nh0/myomlt.git
   ```
2. Entre na pasta:
   ```bash
   cd myomlt
   ```
3. Abra o `index.html` no navegador.

## 🌐 Publicação (opcional)

Você pode publicar com **GitHub Pages**:

1. Vá em **Settings** do repositório
2. Acesse **Pages**
3. Em **Source**, selecione a branch principal e a pasta raiz (`/root`)
4. Salve e aguarde o link de publicação
